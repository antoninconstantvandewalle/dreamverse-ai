# DreamVerse AI

Prototype gratuit de site statique avec un salon de discussion en français et deux personnages fictifs explicitement adultes : Sophie (34 ans) et Isabelle (36 ans).

## Déploiement Cloudflare Pages
- Framework preset : None
- Production branch : main
- Build command : laisser vide
- Build output directory : .
- Root directory : / (racine du dépôt)

Le site est une interface statique. Le mode de discussion fourni est une démonstration à réponses prédéfinies, pas un grand modèle IA hébergé. Il ne nécessite aucune clé API.

## Images et vidéos
La page contient un espace de préparation de prompt, mais ne génère pas elle-même d'images ou de vidéos. Une génération réellement gratuite demande un moteur local tel que ComfyUI, les modèles compatibles et le matériel nécessaire sur l'ordinateur de l'utilisateur. Cloudflare Pages n'héberge pas gratuitement un GPU de génération pour chaque visiteur.

## Confidentialité et sécurité
Les messages ne sont pas envoyés à un backend par ce prototype. Utilise uniquement des personnages fictifs adultes et respecte les lois applicables, les licences des modèles et le consentement des personnes représentées. N'utilise pas l'image intime d'une personne réelle sans son consentement.
